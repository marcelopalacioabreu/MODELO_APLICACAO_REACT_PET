Fluxo de autenticação (sequência)

sequenceDiagram participant U as Usuário participant LC as LoginComponent participant API as apiService participant BE as Backend participant AUTH as AuthContext U->>LC: submete credenciais LC->>API: POST /auth/login API->>BE: requisição HTTP BE-->>API: retorna {accessToken, refreshToken} LC->>AUTH: AUTH.login(tokens) AUTH->>LocalStorage: set token / refreshToken AUTH->>API: GET /auth/me (getMe) API->>BE: requisição HTTP BE-->>API: user data AUTH->>Socket: conecta via socket.io (auth token) AUTH-->>Router: push /admin

Chamadas API - responsabilidades (resumo)

services/apiService.ts
  • Autenticação: /auth (login, me, logout, change-password)
  • Pets: /pets, /pets/lost, /pets/adoptable
  • Feed: /feed (public/private)
  • Admin: /admin/* (roles, users, permissions)
  • Inventory: /inventory/* (products, stock, transactions)
  • Hotelaria: /beds
  • Appointments & Triage: /appointments, /triage

ArtefatoPapel

`src/services/apiService.ts`Axios wrapper, interceptors e chamadas organizadas por domínio
`src/utils`Helpers (textParser, cpfUtils)
`package.json`Dependências: Next.js, React, Tailwind, Framer Motion, Socket.IO client, Recharts, axios, etc.

Tema / Variáveis principais (Tailwind)

As cores principais estendidas em tailwind.config.ts e src/app/globals.css:

  • --primary-green / primary-green: #006644
  • --primary-teal / primary-teal: #004d40
  • bg-light / --bg-light: #f8fafc / #f4f4f4 (variações)
  • Também existem animações e utilitários: `fadeIn`, `slideUp` e background gradients.

Como inspecionar / editar

  1. Edite o arquivo fonte legível: frontend_structure.mmd.
  2. Abra `index.html` no navegador (duplo-clique); os diagramas são renderizados pelo Mermaid CDN.
  3. Se quiser atualizar, copie/cole o bloco mermaid do `.mmd` para dentro de um dos div.mermaid no `index.html` (ou reabrir).
